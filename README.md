# Risacca

Installer desktop basato su FreeBSD 15.1 per PC Intel e AMD a 64 bit. Il desktop Xfce include Firefox ESR, LibreOffice, VLC e firmware Wi-Fi e Bluetooth.

La procedura di build e la guida di installazione sono in [Risacca/LEGGIMI.md](Risacca/LEGGIMI.md). Le build completate rendono disponibili l’ISO e il checksum SHA-256 dalla [pagina Actions](../../actions).
